# 电子负载 UI 设计文档

> 目标屏：ST7735 **160×128 横屏**  
> 风格：深色仪表盘（黑底 + 青/琥珀高亮）  
> 入口实现：`loader_ui.c`（声明见 `loader_task.h`）  
> 数据契约：只读/写设定走 `loader_runtime` + `loader_core` request API，不写 DAC/GPIO 执行器  
> 关联：`LOADER_DESIGN.md`、硬件显示见 `doc/hardware.md`（ST7735 / `tft_fb`）

---

## 1. 目标与约束

| 项 | 约定 |
|----|------|
| 分辨率 | **160×128** 横屏（`tft_fb_init` rotation=1，与 `mjc_config.h` 默认一致） |
| 风格 | 深色仪表盘：黑底 + 冰青/琥珀/状态色 |
| 主信息 | 大号 **V / I / P**；下方 **电流动态折线** |
| 页面 | 主监控 / 设定 / 状态保护 / 全屏图表 / 关于 |
| 输入 | 预留 4 键：上 / 下 / 确认 / 返回（multi_button 适配层） |
| 绘制 | 自定义仪表盘（`tft_fb` + Adafruit GFX）；设定/列表页可复用列表思路，不必整页绑死 MujicaUI 菜单渲染 |
| 刷新 | UI 任务约 **20–50 ms**；控制环与 UI 分离（见 `LOADER_DESIGN.md`） |

屏很小，原则：

1. **主页一眼读数**，少字多形。  
2. **次页列表化**，避免一屏塞满。  
3. **一量一色**，状态用胶囊/色条，动效克制。

## 3. 页面地图与导航

```
              ┌─────────────┐
   上电 ─────►│  0 主监控   │◄──── 返回（从其它页）
              └──────┬──────┘
                     │ 上/下 切换页签；确认见各页语义
                     ▼
         ┌───────────────────────────┐
         │ 1 设定  2 状态  3 图表  4 关于 │
         └───────────────────────────┘
```

**页签顺序（循环）**

`主监控(0) → 设定(1) → 状态(2) → 图表(3) → 关于(4) → 主监控…`

### 3.1 全局按键语义

| 键 | 主监控 | 列表页（设定/状态/关于） | 图表页 | 编辑设定值时 |
|----|--------|--------------------------|--------|--------------|
| **上** | 下一页签 | 上一项 | 切换 I / P 曲线 | 设定值 +step |
| **下** | 上一页签 | 下一项 | 切换 I / P 曲线 | 设定值 −step |
| **确认** | **切换输出 ON/OFF** | 进入编辑 / 触发动作 | 暂停 / 继续滚屏 | 退出编辑并保存 |
| **返回** | 无效（已是根） | 回主监控 | 回主监控 | 取消编辑并回列表 |

说明：

- 主监控 **短按确认 = ON/OFF**（最高频操作）。  
- 可选二期：主监控 **长按确认** 直达设定页。  
- ON → `loader_core_request_run()`；OFF → `loader_core_request_stop()`。  
- 故障态 ON 可能失败（`EXIT_BUSY`），UI 应保持显示 ERROR，不假装已 RUN。

### 3.2 页面枚举（实现建议）

```c
typedef enum {
    UI_PAGE_HOME = 0,
    UI_PAGE_SET,
    UI_PAGE_STATUS,
    UI_PAGE_CHART,
    UI_PAGE_ABOUT,
    UI_PAGE_COUNT
} ui_page_t;
```

## 4. 页面线框与布局

坐标原点：左上 (0,0)；宽 160，高 128。

### 4.0 页面 0 — 主监控（核心）

```
┌────────────────────────────────────────┐  y=0
│ CC · RUN          25.3°C      [ON]     │  顶栏 12px
│────────────────────────────────────────│
│  12.345 V                              │  电压 大字
│   1.234 A          15.21 W             │  电流 / 功率
│  Set 1.000A                            │  当前模式设定
│┌──────────────────────────────────────┐│
││ ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ││  折线区
││     ╱╲      ╱╲                       ││
││────╱  ╲────╱  ╲──────────────────────││
││                                       ││
│└──────────────────────────────────────┘│
│ I  0.0···············2.5········5.0 A │  刻度
│ ● 主  ○设 ○态 ○图 ○关                  │  底栏页签
└────────────────────────────────────────┘  y=127
```

| 区 | y 范围（建议） | 内容 |
|----|----------------|------|
| 顶栏 | 0–11 | 模式 `CC/CV/CR/CP` · 状态 `IDLE/RUN/FAULT` · 温度 · ON/OFF 胶囊 |
| 读数区 | 12–55 | 电压（最大号）+ 电流(琥珀) + 功率(白) + 设定一行灰字 |
| 图表 | 56–112 | 细框 + 网格 + 电流滚动折线 |
| 底栏 | 113–127 | 5 个页签指示 |

**故障时**：顶栏整条红底白字，例如 `FAULT: OCP`；测量与折线继续刷新。

**顶栏字段绑定**

| 显示 | 来源 |
|------|------|
| 模式 | `runtime.mode` |
| 状态 | `runtime.state`（`LOADER_STATE_*`） |
| 温度 | `runtime.temperature_measurement` |
| ON/OFF | `state == RUNNING` 视为 ON，否则 OFF（或结合业务“输出使能”语义统一） |

**读数字段**

| 显示 | 来源 | 格式 | 色 |
|------|------|------|-----|
| V | `voltage_measurement` | `xx.xxx` + `V` | 青 size3 |
| I | `current_measurement` | `x.xxx` + `A` | 琥珀 size2 |
| P | `power_measurement` | `xx.xx` + `W` | 白 size2 |
| Set | 当前模式对应 `*_setpoint` | `Set x.xxxU` | 灰 size1 |

设定行单位随模式：`A` / `V` / `W` / `Ω`。

### 4.1 页面 1 — 设定

```
┌────────────────────────────────────────┐
│ ◄ 设定                          1/5    │
│────────────────────────────────────────│
│  ▶ 模式          [ CC ]                │
│    设定值        1.000 A               │
│    输出          OFF → ON              │
│    步进          0.01 / 0.1 / 1.0      │
│    应用并返回                          │
│                                        │
│  说明: CC 下设定值为电流               │
└────────────────────────────────────────┘
```

| 条目 | 行为 |
|------|------|
| 模式 | 确认循环：`CC → CV → CR → CP`，写 `runtime.mode` |
| 设定值 | 进入编辑态：数值反色/闪烁；上下按 step 调节；确认写对应 `*_setpoint` |
| 输出 | 确认切换 run/stop |
| 步进 | 确认在 `0.01 / 0.1 / 1.0` 三档间切换 |
| 应用并返回 | 确认后回主监控（若设定已即时写入，可仅返回） |

**编辑态**：上下调值，确认保存，返回取消（恢复进入编辑前的值）。

**限幅**（与 `loader_config.h` / 产品限值一致，实现时用宏）：

- 电流设定：`0 … LOADER_CURRENT_MAX`  
- 其它模式：按产品满量程钳位（文档实现阶段与 config 对齐）

### 4.3 页面 3 — 全屏图表

```
┌────────────────────────────────────────┐
│ I · 5s窗口 · auto  1.234A peak 2.1   │
│┌──────────────────────────────────────┐│
││        ╱╲                            ││
││   ╱╲  ╱  ╲    ╱╲                     ││
││──╱  ╲╱    ╲──╱  ╲──────────────────  ││
```

| 操作 | 行为 |
|------|------|
| 上 / 下 | 切换 **电流曲线** / **功率曲线** |
| 确认 | 暂停采样滚屏（定格）/ 继续 |
| 返回 | 回主监控 |

**Y 轴**：

- 主页图：固定 `0 ~ LOADER_CURRENT_MAX`（简单稳定）。  
- 全屏：auto 量程，建议 `max(peak * 1.2, fullscale * 0.2)`；防抖：量程只升不降，或 ≥2 s 后再降。

## 5. 电流折线图

| 参数 | 建议 |
|------|------|
| 缓冲长度 | **80–100** 点（接近图区宽度） |
| 采样周期 | UI 任务约 **50 ms** 取 1 点 → 窗口约 **4–5 s** |
| 主页图区 | 约 x:4..155，y:58..108（≈152×50） |
| 线色 / 线宽 | 琥珀 `0xFD20` / 1 px |
| 网格 | 水平 2 条 + 垂直 3 条，暗灰 |
| 滚动 | 环形缓冲，新点在右侧，整体左移显示 |
| 重绘 | 优先 `tft_fb_flush_rect` 只刷图区 |

### 5.1 算法概要

```text
float ring[N];
uint16_t head;   // 下一个写入位置
bool chart_paused;

each ui tick (if !paused):
  ring[head] = sample;   // I 或 P
  head = (head + 1) % N

draw:
  clear chart rect
  draw grid
  for i in 0..N-1:
    idx = (head + i) % N   // oldest → newest
    x = chart_x0 + i * (chart_w-1) / (N-1)
    y = map(ring[idx], y_min, y_max, chart_y1, chart_y0)
    line from prev to (x,y)
  flush_rect(chart)
```

主页始终采样 **电流**；全屏页按当前通道采样 I 或 P（可共用缓冲或分通道缓冲，实现自选；分通道更清晰）。

## 6. 数字显示与脏刷新

### 6.1 格式

| 量 | 格式 | 对齐 |
|----|------|------|
| V | `xx.xxx` | 固定宽度，避免跳变晃动 |
| I | `x.xxx` | 同上 |
| P | `xx.xx` | 同上 |
| T | `xx.x` | 顶栏 |
| 设定 | 随步进精度 | 编辑态可提高显示精度 |

### 6.2 脏更新策略

- 数值：仅当 `|new - shown|` 超过显示分辨率一半，或跨格式边界时重画该字段。  
- 状态/模式/故障/页签：变化即重画对应区域。  
- 折线：每采样点重画图区（或隔帧，保 15–20 Hz 观感即可）。  
- 全屏切换页：整屏 `fill` + 全量绘制 + `tft_fb_flush()`。

## 7. 软件结构

### 7.1 对外 API（建议放 `loader_task.h`）

```c
void loader_ui_init(void);
void loader_ui_poll(void);   /* 20–50 ms 周期任务调用 */
```

### 7.2 文件内模块划分（`loader_ui.c`，可按需拆 static 区）

| 模块 | 职责 |
|------|------|
| `ui_nav` | 当前页、列表选中索引、编辑态、步进档位 |
| `ui_input` | 四键事件 → 导航/编辑/request_run/stop |
| `ui_fmt` | float → 固定宽度字符串 |
| `ui_chart` | 环形缓冲 + 折线绘制 |
| `ui_draw_home` | 主监控 |
| `ui_draw_set` | 设定页 |
| `ui_draw_status` | 状态/保护 |
| `ui_draw_chart` | 全屏图 |
| `ui_draw_about` | 关于 |

### 7.3 依赖方向

```
loader_ui
  ├── loader_runtime_get / 写设定字段
  ├── loader_core_request_run / stop / clear_fault
  ├── tft_fb / mjc_hal 绘制
  └── multi_button / mjc_input_button（四键预留）

禁止：HAL_DAC、load_out_* 直接调用、在 UI 里做保护判定
```

### 7.4 主循环伪代码

```text
loader_ui_init():
  显示 init（横屏 160×128）
  按键 init（上/下/确认/返回）
  chart ring 清零
  page = HOME

loader_ui_poll():
  rt = loader_runtime_get()
  处理按键队列 → 改 page / 编辑 / core request
  if !chart_paused: chart_push(rt.current or power)
  switch page: draw_*
  分区或全屏 flush
```

### 7.5 与任务系统

| 调用方 | 周期 | 说明 |
|--------|------|------|
| `loader_task` / UI 任务 | 20–50 ms | 只调 `loader_ui_poll()` |
| 控制 | 0.5 ms 量级 | 不碰 UI |

硬件按键未齐时：可用 PC13 单键 mock 映射，或 CLI 模拟页切换；接口仍按四键事件表实现。

## 8. 交互时序（主路径）

```text
设定页: 模式 CC，设定 1.0 A，输出 ON
  → runtime.mode = CC
  → runtime.current_setpoint = 1.0
  → loader_core_request_run()
  → 主页顶栏 RUN + [ON]，I 与折线上升

保护触发 OCP
  → runtime.state = ERROR, error = OVERCURRENT
  → 主页顶栏红条 FAULT
  → 状态页 Clear → clear_fault → IDLE
  → 用户再次 ON 才进入 RUN
```

## 9. 视觉原则（小屏）

1. **留白**：读数区少画重框，图区细线框即可。  
2. **颜色分工**：V 青、I 琥珀、P 白、状态绿/红。  
3. **层次**：顶/底栏低对比，中间读数最高对比。  
4. **动效**：故障条约 500 ms 闪；ON 胶囊常亮；折线连续滚动。  
5. **一致**：各页顶栏高度、返回语义、页签顺序统一。
