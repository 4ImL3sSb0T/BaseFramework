- 修 UI 缺陷：卡片内所有文字后面有一层错色背景（浅色下灰带、深色下近黑带）。根因是 `theme.stylesheet()` 的通用选择器 `QWidget { background: BG }` 命中 QLabel，而 QLabel 继承自 QFrame、**会**绘制 QSS 背景，于是每个 label 都在卡片底色上刷了一块窗口基色。修法：在 `QWidget` 规则之后加 `QLabel { background: transparent; }`（同为类型选择器，后写的胜出）。注意：**不要**改成"去掉 QWidget 的背景、只给 QMainWindow 上色"——那会让 `QScrollArea` 的 viewport 掉回 Qt 默认调色板色 `#efefef`，左右两栏底色会变。验证手段：`QT_QPA_PLATFORM=offscreen` 截图 + 逐像素扫描（`_scan_bands.py` / `_crop_cmp.py` / `_shot_theme.py`）。
